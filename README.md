# Formula

Мобильный тренажёр формул ЕГЭ по физике. Работает локально, без аккаунта и платных сервисов. Каталог перенесён **только из предоставленного файла «Формулы ЕГЭ (обновленные).docx»**: 127 записей объединяют 183 математических выражения. Три повторяющиеся записи с одинаковым названием и выражением объединены между темами. Для каждой записи сохранены номера абзацев исходного документа.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который выведет Vite. Для проверки сборки и тестов:

```powershell
npm.cmd run test
npm.cmd run build
npm.cmd run preview
```

Для доступа с телефона в одной сети запустите `npm.cmd run dev`, затем откройте сетевой адрес компьютера. Установка PWA обычно требует HTTPS; локальный `localhost` также подходит. Для бесплатного статического хостинга опубликуйте содержимое `dist/` на GitHub Pages, Cloudflare Pages или Netlify. Для подпути на GitHub Pages задайте `base` в `vite.config.ts` до сборки.

## Структура

- `src/data/catalog.full.json` — действующий каталог из Word-файла.
- `scripts/extract_word.py` и `scripts/build_catalog.py` — воспроизводимый перенос математических объектов Word и привязка к исходным абзацам.
- `scripts/check_catalog.mjs` — проверка математической записи через KaTeX и структуры каталога.
- `src/lib/catalog.ts` — уникальные формулы и генерация направленных карточек.
- `src/lib/srs.ts` — интервальные повторения.
- `src/lib/storage.ts` — IndexedDB, резервные копии и миграция схемы.
- `src/lib/stats.ts` — показатели по карточкам и уникальным формулам.
- `src/lib/quiz.ts` — проверяемые варианты теста.
- `src/App.tsx` — экраны и действия.

## Добавление полного набора

В `src/data/catalog.full.json` разделы (`sections`), темы (`topics`) и формулы (`formulas`) хранятся отдельно. Каждая формула имеет постоянный `id` и массив `topicIds`. Если она нужна в двух темах, добавьте оба ID в `topicIds`; вторую копию формулы не создавайте. Пример структуры из каталога:

```json
{
  "id": "kinematics-4-peremeschenie-pri-ravnomernom-dvizhenii",
  "sectionId": "mechanics",
  "topicIds": ["kinematics"],
  "subtopic": "Прямолинейное движение",
  "title": "Перемещение при равномерном движении",
  "latex": "\\vec{s}=\\vec{v}t",
  "symbols": [
    {"symbol": "s", "meaning": "путь, перемещение", "unit": "м", "sourceParagraph": 6},
    {"symbol": "v", "meaning": "скорость", "unit": "м/с", "sourceParagraph": 8},
    {"symbol": "t", "meaning": "время", "unit": "с", "sourceParagraph": 12}
  ],
  "conditions": "В файле условия отдельно не указаны.",
  "explanation": "",
  "source": "verified",
  "sourceParagraphs": [4, 5]
}
```

При обновлении исходного набора сверяйте математическую запись, обозначения, единицы, условия и принадлежность к темам. Сохраняйте старые ID: они связаны с прогрессом пользователя. Новые записи автоматически создают карточки для двух направлений формулы и двух направлений каждого расшифрованного обозначения. Неоднозначные буквы всегда показаны с контекстом конкретной формулы. Если альтернатив для теста недостаточно, карточка не включается в тест. Если исходный документ не расшифровывает индекс или величину, приложение не придумывает пояснение.

Для повторного извлечения из той же версии Word-файла запустите команды из корня проекта (путь к документу замените на актуальный):

```powershell
python scripts/extract_word.py "C:\путь\к\Формулы ЕГЭ (обновленные).docx" scripts/word_paragraphs.json > scripts/word_paragraphs.txt
python scripts/build_catalog.py
node scripts/check_catalog.mjs
npm.cmd run test
```

`build_catalog.py` содержит явное сопоставление абзацев, формул и тем для этой версии файла. Если структура Word-документа изменится, сначала обновите сопоставление и проверьте номера исходных абзацев.

## Прогресс и резервные копии

Прогресс хранится в IndexedDB этого браузера (`formula-progress`, схема v2): таблицы `progress`, `answers`, `meta`. Для каждого ID карточки сохраняются показы, успешные ответы, ошибки, история оценок, интервалы и следующая дата. Ответ и позиция сессии сохраняются одной транзакцией после каждого ответа. При обновлении страницы незавершённая сессия восстанавливается кнопкой «Продолжить сессию».

«Пройдено» означает, что карточка получила хотя бы одну оценку; этот процент растёт уже после первого занятия, даже при ответе «Не знаю». «Освоено» означает не менее трёх успешных повторений с интервалом от семи дней. Общий процент считается по уникальным направленным карточкам, а на странице темы дополнительно показан прогресс выбранного режима. Одна формула в нескольких темах учитывается в каждой теме, но только один раз в общем итоге.

В «Настройках» можно выгрузить JSON и импортировать его обратно. Импорт проверяет структуру и ID, затем объединяет данные; существующие записи, которых нет в файле, сохраняются. Перед импортом показывается подтверждение. Для переноса между телефонами нужен экспорт и ручной импорт. При удалении данных браузера без резервной копии прогресс восстановить нельзя.

История от прежнего демонстрационного каталога сохраняется в резервной копии, но не включается в показатели нынешних карточек. Сессии с удалёнными ID автоматически не восстанавливаются. Это предотвращает смешение результатов по разным формулам.

## Реализовано

Главная, каталог разделов и тем, поиск, справочник, четыре направления карточек, тест, повторы и ошибки, избранное, случайная тренировка по выбранным разделам, фильтры, настройка количества новых карточек, локальная статистика, светлая и тёмная темы, PWA и офлайн работа после первой загрузки.

## Ограничения

- Каталог покрывает математические выражения, приведённые в предоставленном файле. Это не сверка с действующим официальным кодификатором ЕГЭ.
- В документе отдельные единицы и числовые справочные данные выглядят противоречиво. Сомнительные единицы в абзацах 240, 641 и 705 не добавлены в учебные подсказки. Отдельную справочную строку 716 с переводом эВ в Дж не превратили в карточку из-за вероятной ошибки в показателе степени. Исходные формулы и текстовые оговорки сохранены с привязкой к абзацам.
- Для обозначений, не расшифрованных в файле, карточки обозначений не создаются. Формулы с такими символами остаются доступными в справочнике и режимах изучения формул.
- Данные хранятся только в текущем браузере. Аккаунтов и автоматической синхронизации нет.
- Оценка карточек основана на самооценке; тесты проверяются автоматически.
- PWA не может гарантировать сохранность данных, если пользователь очищает хранилище браузера.
- Для установки и офлайн работы нужен первый успешный визит по HTTPS или localhost.
